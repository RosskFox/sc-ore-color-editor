How to use the INI Color Editor

Color-label ores, commodities, and ship components in Star Citizen by editing global.ini with <EM> emphasis tags. No files leave your browser — everything runs locally.

Installation

  1. Open the editor — it auto-loads the MrKraken StarStrings community pack as a starting point. You can also drop your own global.ini onto the left pane, or pick another community pack from the dropdown.
  2. In the center Keys pane, find the key you want to color-label. Use the search box (* works as a wildcard) and the category filter to narrow the list.
  3. For each key, pick an EM tag from the dropdown — EM2 for green or EM4 for red. Optionally edit the displayed Value text to whatever you want shown in-game.
  4. When you're done, click Download in the right pane to save the modified global.ini (or Copy to clipboard). Use Changes only mode if you just want the keys you edited.
  5. If you already have a user.cfg file, do not overwrite it. Instead, open your existing user.cfg and add the following line at the end g_language = english
  6. Copy the downloaded global.ini into your game's LIVE folder, replacing the existing one.
  7. Launch the game (if it was already running, fully quit with Alt+F4 and relaunch — Star Citizen reads global.ini only once at startup).
StarCitizen/
└── LIVE/
    ├── user.cfg
    └── data/
        └── Localization/
            └── english/
                └── global.ini

Heads up: Star Citizen loads global.ini a single time at launch. There is no live reload — you must restart the game for changes to appear. Setting g_language = english in user.cfg ensures the game reads your custom file instead of the default localization.

EM color tags

The game wraps display text in <EMn>…</EMn> tags to apply color. This editor exposes the two that work reliably for labels:

TagColorExample output
EM2Green<EM2>Carinite (Pure)</EM2>
EM4Red<EM4>Quantainium (Raw)</EM4>

Tips

  1. Keys you modify but that aren't in your loaded file are still added to the output automatically.
  2. Click the Value column header to sort A→Z or Z→A. Click again to return to default order.
  3. The Modified filter chip shows only keys you've tagged or edited — handy for reviewing before you download.
  4. The known-keys list (89,000+ keys merged from 5 community packs) refreshes automatically each day; the badge in the header shows the last refresh date.

Built on community language packs — BeltaKoda Remix, ExoAE, MrKraken StarStrings, and the stock LIVE global.ini. Source on GitHub.
